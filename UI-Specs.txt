5. Step-by-Step Technical Checklist for Mirroring into Apache Hop Web
Follow these steps to apply this design system directly into your Apache Hop Web deployment:

Locate Hop Theme Bundle:
In your Hop Web deployment/RAP installation directory (usually under plugins/org.apache.hop.web... or your custom RAP branding bundle), locate the active CSS theme (often theme/theme.css or branding/theme.css).
Copy Visual Brand Assets:
Transfer public/images/logo.png to Hop Web's image directory (/images/logo.png or branding/logo.png).
Configure Hop Web's branding.properties to set branding.logo=images/logo.png and update the page title to match.
Inject CSS Variables & Rules:
Prepend the :root token variables and RAP selector rules from Section 4.1 into your Hop Web theme stylesheet.
Customize Canvas Grid & Node Selection:
Ensure the pipeline canvas background uses the 20px dot grid pattern with #E2E8F0 dots on a #FAFAFA background.
Set transform/action active border selection to #1976D2 with a 3px glow ring.
Adjust Tab & Sidebar Accents:
Verify that active pipeline tabs use the #1976D2 bottom border indicator and that sidebar tree items display the #E3F2FD hover and #1976D2 active border markers.
Deploy & Validate:
Rebuild/restart the Hop Web container or refresh the RAP theme bundle cache to verify button states, tab switching, and table metrics styling against this reference.
